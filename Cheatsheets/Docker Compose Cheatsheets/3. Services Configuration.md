Image vs Build

Using prebuilt image
```yml
services:
  web:
    image: nginx:latest
```

Using Dockerfile
```yml
services:
  api:
    build: .
```


Build with context and Dockerfile
```yml
services:
  api:
    build:
      context: .
      dockerfile: Dockerfile
```

Ports
```yml
ports:
  - "8080:80"
  - "127.0.0.1:5000:5000"
```

Format:
```
HOST:CONTAINER
```

Restart Policies
```yml
restart: "no"
restart: always
restart: unless-stopped
restart: on-failure
restart: on-failure:5
```

Depends On
```yml
depends_on:
  - db
```

⚠️ Only controls startup order
Does NOT wait for DB to be “ready”

Command Override
```yml
command: ["npm", "start"]
command: python app.py
```

Entrypoint Override
```yml
entrypoint: ["./entrypoint.sh"]
```

Working Directory
```yml
working_dir: /app
```

Container Name
```yml
container_name: my-custom-container
```
