Default Behavior

Compose automatically:
Creates a network
Attaches all services
Enables service-to-service DNS

Example:

http://db:5432

Custom Network
```yml
networks:
  backend:
```

Attach to service:
```yml
services:
  api:
    networks:
      - backend
      - frontend # multiple networks
```

Define Network

```yml
networks:
  backend:
    driver: bridge
```
