
Environment Inline
```yml
environment:
  - NODE_ENV=production
  - PORT=5000
```

OR

```yml
environment:
  NODE_ENV: production
  PORT: 5000
```

env_file
```yml
env_file:
  - .env
  - prod.env
```

Docker Compose automatically reads:
.env

In same directory.

Secrets (Swarm mode mainly)
```yml
secrets:
  mysecret:
    file: ./secret.txt
```

Attach:
```yml
services:
  api:
    secrets:
      - mysecret
```
