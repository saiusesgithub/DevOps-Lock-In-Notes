Help + quick docs

```bash
docker --help
docker <command> --help
docker help <command>
```

Common “what’s running / what exists”

```bash
docker ps
docker ps -a

docker images
docker image ls

docker container ls
docker container ls -a

docker volume ls
docker network ls
```

Inspect / metadata

```bash
docker inspect <container_or_image>
docker image inspect <image>
docker volume inspect <volume>
docker network inspect <network>
```
